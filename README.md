## Descripción del trabajo

Este trabajo práctico reúne una investigación sobre Git y GitHub, sus diferencias y las herramientas que ayudan a organizar proyectos de programación y trabajar en equipo. También incluye comparaciones entre las definiciones investigadas y la documentación oficial de GitHub.

## Temas investigados

### Git

Git es un sistema de control de versiones distribuido. Permite registrar cambios en los archivos de un proyecto y consultar versiones anteriores, incluso trabajando con una copia local.

### GitHub

GitHub es una plataforma en línea para alojar repositorios y colaborar en proyectos de software. Ofrece herramientas para compartir código, revisar cambios y organizar tareas.

### Diferencia entre Git y GitHub

Git registra y administra versiones de archivos. GitHub aloja proyectos que usan Git y agrega herramientas de colaboración en línea.

### Repositorios

Un repositorio es un espacio donde se almacenan y organizan los archivos de un proyecto, junto con el historial de cambios cuando se usa Git.

### README

Un archivo `README.md` explica de qué trata un repositorio, qué contiene y cómo utilizarlo. Normalmente se muestra en la página principal del proyecto en GitHub.

### Commit

Un *commit* es un registro de cambios en uno o más archivos. Funciona como un punto de guardado del proyecto e incluye un mensaje que describe lo que se modificó.

### Ventajas del control de versiones

El control de versiones permite seguir los cambios del código a lo largo del tiempo, revisar el historial y colaborar sin perder de vista qué se modificó.

## Funciones de GitHub mencionadas en el trabajo

- **Pull requests:** proponer, revisar y discutir cambios antes de integrarlos.
- **Issues y proyectos:** organizar errores, mejoras y tareas pendientes.
- **GitHub Actions:** automatizar procesos como pruebas y compilaciones.
- **GitHub Pages:** publicar sitios web estáticos.
- **Seguridad:** administrar accesos y utilizar herramientas de protección.
- **GitHub Copilot:** obtener sugerencias de programación asistidas por IA.

## Comparación con la documentación oficial

En el TP7 se comparan especialmente los conceptos de **README** y **commit** con la documentación de GitHub. La comparación muestra que las definiciones iniciales coinciden en lo esencial, pero las explicaciones oficiales incluyen más detalles, por ejemplo qué información debe contener un README y cómo se identifican los commits.

También se destaca la importancia de verificar las respuestas de una inteligencia artificial con fuentes oficiales.
